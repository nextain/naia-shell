# 근거와 답변의 범위

모르는 질문이나 내부 정보도 답해 주나요라는 질문에 답하면, 이 시연은 **공개 지식 근거 안에서 답변**하며 확인 전 수치·비공개 자료를 추측하지 않고 계획과 구현을 구분해 안내합니다. 자료에 없는 숫자나 개인 정보, 비공개 고객과 업무 내용은 추측해 만들지 않습니다. 확인이 필요한 내용은 확인이 필요하다고 답하고, 제품 계획은 계획이라고 밝힙니다. 로컬 저장은 외부 모델로 아무 내용도 전달되지 않는다는 뜻과 구분해야 하며 실제 선택한 모델과 환경을 기준으로 설명합니다. 아직 실증 전인 가게 비서나 추가 기능은 적용 예시로 소개하고 확정된 제품 성능이나 결과로 약속하지 않습니다.
