# 컨테이너판 0.2.6 개발 상태

컨테이너판 0.2.6은 **내 PC의 로컬 모델을 웹 화면으로 쓰는 판**입니다. 2026-11-05 상태 문서에는 웹판 위로 이식해 독립 검수를 마쳤고, 웹 화면과 로컬 모델 서버 기동·모델 선택·스트리밍·취소·기억 내보내기와 가져오기를 확인했다고 기록합니다. GPU 실기, 메모리 부족과 폴백, 공개 이미지와 복구 문서는 후속 검증 항목입니다. 이번 음성 IR 키오스크 범위에서는 WebGPU·컨테이너판을 제외했습니다. 제품 확장 방향과 이번 방문자가 체험하는 기능을 구분해 설명합니다.
