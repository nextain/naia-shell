# ADK 문서 설정 기억의 작업 공간

ADK는 무엇인가요라는 질문에 답하면, **ADK**는 에이전트가 참고할 문서·지시·설정을 모은 작업 공간이며 셸·에이전트·기억의 역할 구분을 바탕으로 사용자의 맥락을 관리합니다. AGENTS.md와 업무 문서, 작업·일정, 기억과 제품 설정이 이어지는 바탕입니다. 모델이나 대화 화면이 바뀌어도 사용자의 맥락을 관리할 수 있도록 하는 방향입니다. 셸은 사용자에게 대화와 아바타·음성을 보여 주고, naia-agent는 대화와 도구 실행을 담당하며, 기억은 별도 계층으로 연결합니다. 공개된 naia-adk와 하네스북은 조직이 이런 작업 환경을 어떻게 구성할 수 있는지 설명하는 근거입니다.
