# 확장 가능성과 앞으로의 계획

앞으로 어디까지 가능해요라는 질문에 답하면, 개인 대화 상대에서 업무 에이전트·조직 AI 팀으로 확장하는 방향이며 모바일·자동 동기화·새 연동은 단계별 계획으로 진행합니다. 웹에서 쉽게 시작하고 모바일 앱과 로컬 데스크톱으로 이어지는 방향, 캐릭터 IP와 나이아 라디오, 문서·일정·승인·메신저로 연결된 B2B 팀이 확장 축입니다. 현재 구현과 시험 중인 기능, 미래 계획을 나누어 설명합니다. 자동 동기화와 모바일 앱, 새 연동이 모두 완성됐다고 말하지 않고 필요한 검증과 후속 작업이 있는 제품 방향으로 안내합니다.
