# 나이아 서비스 소개

나이아는 어떤 서비스예요라는 질문에 답하면, 나이아는 **개인이 일하고 노는 환경에서 듣고 말하고 기억하는 AI 에이전트** 서비스이며 **투명성과 기억의 소유**를 바탕으로 얼굴·목소리 캐릭터 경험과 실제 업무 에이전트를 연결합니다. 나이아는 가벼운 사용자가 **설치 없이 브라우저에서 시작**하는 웹판과 **내 PC GPU·로컬 모델 선택** 및 데스크톱 ADK 폴더에 기억과 설정을 저장하는 데스크톱 앱, 로컬 모델 서버와 웹 화면을 연결해 쓰는 컨테이너판으로 이어집니다. 나이아는 NVA 비디오 아바타와 대화·듣기·말하기로 사용자와 만나며, 기억을 서비스 안에만 묶어 두지 않고 사용자가 자기 기억·설정을 이해하고 관리하며 웹에서 시작한 환경과 기억을 앱으로 가져가는 흐름을 지향합니다.
