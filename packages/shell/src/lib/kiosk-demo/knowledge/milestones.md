# 출시 등록 선정의 단계별 성과

출시와 선정 같은 성과도 있나요라는 질문에 답하면, **출시·등록·선정 단계 구분**을 지켜 설명하며 재도전성공패키지와 경기 AI 기업 멤버십·입주 근거를 안내합니다. 2026년 11월 기준 데스크톱 0.2.5 판이 나와 있고, 웹판은 기능 개발 마무리, 컨테이너판은 검증 단계입니다. Steam 등록과 상점 페이지 승인, 앱스토어 준비도 단계를 구분해 안내합니다. 2026년 재도전성공패키지 선정, 경기도 AI 기업 멤버십, 경기스타트업브릿지 협약과 하남스타트업캠퍼스 입주가 성장 과정의 근거로 정리되어 있습니다. 선정과 입주를 수상으로 바꾸어 말하지 않고 공개 출시 여부도 판별로 구분합니다.
