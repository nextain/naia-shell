# 얼굴 목소리 캐릭터 IP 경험

캐릭터와 IP는 어떤 역할을 하나요라는 질문에 답하면, 나이아는 **얼굴·목소리 캐릭터와 실제 업무 경험 연결**을 맡으며 캐릭터 IP·유통·라디오는 각각 현재 범위와 계획을 구분해 안내합니다. NVA 비디오 아바타와 대화·듣기·말하기가 사용자와 만나는 표현 방식입니다. Naia Shell은 아바타·모델·목소리·배경·앱을 경험하는 공간이고, 앱스토어는 유통 경로, 캐릭터 IP는 작가·브랜드 협업 자산이라는 방향입니다. 캐릭터를 대화 상대에서 실제 일을 돕는 에이전트로 발전시키고 조직의 직무별 AI로 이어 가고자 합니다. 나이아 라디오와 추가 협업은 해당 자료의 시점에서 계획으로 소개하며 이번 시연의 실제 제공 기능과 구분합니다.
