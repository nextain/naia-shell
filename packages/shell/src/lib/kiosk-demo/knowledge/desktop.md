# 데스크톱 앱 GPU와 로컬 선택

데스크톱 앱과 웹판은 실행 장소와 로컬 하드웨어 활용 범위에서 달라요. 데스크톱 앱은 **내 PC의 GPU와 로컬 모델**을 활용하려는 사용자, 완전 로컬 환경을 원하는 사용자를 위한 선택입니다. 웹으로 가볍게 시작하고 필요에 따라 앱 환경으로 옮기는 방향입니다. 데스크톱에서는 기억과 설정이 자신의 ADK 폴더에 저장되고 사용하는 모델을 화면에서 확인합니다. 2026-11-05 제품 상태 문서는 데스크톱 0.2.5 출시판의 main 병합을 기록합니다. 웹 화면에서 보이는 기능과 앱의 네이티브 기능은 범위가 다르므로 필요한 기능의 지원 상태를 확인해 안내합니다.
