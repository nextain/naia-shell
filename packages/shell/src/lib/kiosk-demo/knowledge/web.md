# 웹판 브라우저 입구

설치 없이 웹에서 쓸 수 있나요라는 질문에 답하면, 웹판은 가벼운 사용자가 **설치 없이 브라우저에서 시작**하는 기본 입구이며 웹판과 이번 시연의 지원 범위를 구분해 안내합니다. 휴대폰 화면 배치와 파일 탐색기, 기억 내보내기 등이 개발되었습니다. 2026-11-05 제품 상태 문서에서는 웹판 0.2.5 기능 개발이 끝나 PR #824 병합 전이라고 설명합니다. 이번 IR 키오스크는 웹판에서 시연 전용 계정과 준비된 회사 지식을 사용하는 구성입니다. 일반 서비스 전체의 공개 출시나 모든 데스크톱 명령 지원을 뜻하지 않습니다. 시연 화면의 기능은 이 키오스크 범위와 연결된 것부터 안내합니다.
