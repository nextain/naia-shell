# 웹판 브라우저 입구

설치 없이 웹에서 쓸 수 있나요라는 질문에 답하면, 웹판은 가벼운 사용자가 **설치 없이 브라우저에서 시작**하는 기본 입구이며 웹판과 이번 시연의 지원 범위를 구분해 안내합니다. 휴대폰 화면 배치와 파일 탐색기, 기억 내보내기 등이 개발되었습니다. 2026년 11월 기준 웹판 0.2.5는 핵심 기능 개발을 마치고 공개 전 마무리 단계입니다. 이번 IR 시연은 웹판에서 시연 전용 계정과 준비된 회사 지식을 사용하는 구성입니다. 일반 서비스 전체의 공개 출시나 모든 데스크톱 명령 지원을 뜻하지 않습니다. 시연 화면의 기능은 이번 시연 범위에 든 것부터 안내합니다.


웹 버전은 시험판이며 앱스토어와 나이아 메모리는 앱 버전에 먼저 붙이고 있습니다. 목소리는 자체 기술로, 가끔 튀거나 전자음이 섞일 수 있어 계속 다듬고 있습니다. 현재 GPU 한 대(RTX 3090)로 운영하므로 동시 접속이 많으면 느려질 수 있습니다. 웹 버전은 설치 없이 접근할 수 있고 기억이 내 브라우저 저장공간에 남으며 하네스가 공개되어 직접 수정할 수 있습니다.

The web version is a preview; the app store and Naia Memory are being added to the app version first. The voice is our own technology and can occasionally sound uneven or electronic; we are continually improving it. We currently operate on one GPU (RTX 3090), so many simultaneous visitors may experience slowdowns. The web version requires no installation, keeps memories in your browser storage, and offers an open harness you can modify yourself.
