# 기억의 소유와 사용자 통제

**기억의 소유**는 사용자가 자기 AI의 기억과 설정을 이해하고 관리하며 옮겨 쓸 수 있게 하겠다는 제품 가치입니다. 데스크톱의 기억과 설정은 내 PC의 ADK 폴더에 저장합니다. 웹에서 시작한 사용자가 향후 같은 작업 환경과 기억을 앱으로 가져가는 흐름을 지향합니다. 기억을 서비스 안에만 묶어 두지 않고 사용자에게 선택권을 주는 것이 핵심입니다. 실제로 현재 제공되는 내보내기·가져오기 범위는 판마다 확인해야 합니다. 삭제와 동기화 같은 기능도 각각의 검증 상태에 따라 안내합니다.
