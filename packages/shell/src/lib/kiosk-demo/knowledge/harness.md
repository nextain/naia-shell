# 하네스와 신뢰할 수 있는 업무 체계

**하네스**는 AI가 일할 때 참고할 지시·문서·규칙·도구·검토·기록을 묶어 주는 작업 환경입니다. 긴 대화만 믿기보다 파일로 남는 맥락과 확인 절차로 다음 작업에서도 일관성을 유지하도록 돕습니다. 회사에서는 초안 작성과 승인, 실행 뒤 근거 기록을 연결하는 방식으로 사용합니다. 하네스북과 naia-adk에 그 방식을 공개해 사용자가 이해하고 자신의 업무에 맞게 발전시킬 수 있게 합니다. 좋은 모델을 활용하면서도 회사와 사용자 고유의 맥락을 지속시키는 기반이라는 점에 의미가 있습니다.
