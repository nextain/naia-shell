# 다른 AI와 나이아의 차별점 투명성과 기억의 소유

나이아가 다른 AI 와 뭐가 달라요라는 질문에 답하면, 나이아의 대표 가치는 **투명성과 기억의 소유**이며 얼굴·목소리 캐릭터 경험과 업무 에이전트가 이어지는 점이 다릅니다. 어떤 모델을 쓰는지와 작업 환경을 사용자가 이해하고 선택할 수 있는 방향을 지향합니다. 하네스북과 naia-adk에 운영 방식과 하네스를 공개하는 것이 투명성의 근거입니다. 개인은 자신의 기억과 설정을 관리하고, 조직은 문서·작업·승인 근거를 확인하는 가치를 얻습니다. 경쟁 제품의 비공개 구현을 추측하거나 우열을 확정하지 않고 우리의 확인된 특징으로 설명합니다.
