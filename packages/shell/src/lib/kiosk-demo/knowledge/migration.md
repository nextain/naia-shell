# 기억 이관과 자동 동기화의 단계

웹 기억이 PC로 자동 동기화되나요라는 질문에 답하면, **웹과 PC 사이의 기억 이관**은 웹 ZIP 내보내기와 컨테이너 가져오기를 구분하며 데스크톱 자동 동기화는 후속 계획으로 단계별로 제공됩니다. 웹에서는 작업 파일·설정·기억을 ZIP으로 내보낼 수 있고, 데스크톱에서 받아들이기와 자동 동기화는 다음 버전에서 제공할 계획입니다. 컨테이너판은 기억 내보내기·가져오기를 따로 지원합니다. 제품 판마다 지원 범위가 다릅니다. 모든 판에서 자동으로 기억과 문서가 따라간다고 약속하기보다 지금 사용 중인 판의 지원 범위를 설명합니다.
