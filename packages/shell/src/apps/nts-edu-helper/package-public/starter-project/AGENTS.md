# AGENTS.md — 공공 AX기획 실습 도우미 지침

이 프로젝트는 공공기관 AX 서비스 기획 실습 패키지(`nts-ax-planning-studio`)입니다.

## 핵심 작성 원칙

1. **근거 중심 인용**: 모든 법령·수치·변경 문장에는 공개 근거 파일명과 조항 번호를 괄호로 적습니다.
2. **`[[확인 필요]]` 분리**: 제공된 공개 원문으로 확인되지 않는 실무 해석·결재 규정은 추측해 단정하지 않고 `[[확인 필요 — 확인처]]`로 분리해 승인 대상에서 뺍니다.
3. **사람 승인 지점 강제**: AI 에이전트는 초안을 작성하고 검토 요청을 올린 뒤 멈추며, 스스로 "완료"나 "배포"를 선언하지 않습니다.
4. **개인정보 배제**: 납세자·민원인의 실제 개인정보는 입력 자료나 예시 문장에 절대 넣지 않습니다.
