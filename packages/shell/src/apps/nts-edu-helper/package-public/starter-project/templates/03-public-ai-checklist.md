# 공공 AI 체크리스트

> 상위기획·화면기획을 이 표로 검토한다. 판정은 검토를 돕는 표시이고, 법률·보안 승인이 아니다.
> 쓰는 장면: 4교시 여섯 관점 설명, 6교시 위험·승인 검토(전 팀 상호 검토, 대표 팀은 AI 1차 검토 후 사람 확정). 강사용 명령문은 `domain\국세청\명령문.md`의 UC-07.
> 이 표로 특정 서비스가 법상 "고영향 인공지능"에 해당하는지 판정하지 않는다. 해당 여부는 기관이 사전에 검토할 사항이다.

## 판정 기준

| 판정 | 뜻 |
|---|---|
| 확인됨 | 기획서에 대책이 적혀 있고, 근거가 되는 항목 번호를 댈 수 있다 |
| 미확인 | 기획서에 대책이 없거나 부족하다. 보완안을 적는다 |
| 보류 | 기획서만으로 판단할 수 없다. 누구에게 확인할지 적는다(예: 정보화 부서, 개인정보 담당) |

- 모든 질문에 판정을 단다. 빈칸을 남기지 않는다.
- 근거는 기획서 항목 번호로 단다(예: "상위기획 5번", "화면기획 업무 흐름표 4단계").
- 근거가 없으면 판정은 "미확인"이고 근거 칸에 `[[확인 필요]]`를 쓴다.
- AI가 단 판정은 초안이다. "사람 확정" 칸과 위험·조치·책임자는 사람만 채운다. AI가 "확인됨"이라고 쓴 것을 승인으로 취급하지 않는다.

| 4-2 | 승인 기록 다섯 항목(승인자 / 승인 대상과 버전 / 승인 시각 / 승인한 다음 행동 / 반려·수정 사유)이 남는가? 기록은 책임 있는 검토와 사후 확인을 돕는다. 기록만으로 책임 소재가 정해지지는 않는다 | | | |
