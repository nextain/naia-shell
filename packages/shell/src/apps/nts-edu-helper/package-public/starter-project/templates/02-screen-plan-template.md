# 화면기획 (기획서 두 장 중 2장)

<p class="form-note">PC에서 이 문서를 복사해 작성한다. 인쇄본은 PC 장애 시만 쓴다. 사용자가 보는 화면 하나와, 그 화면에서 일이 흐르는 순서와 실패했을 때를 쓰는 장이다. 예쁘게 그리지 않아도 된다. 영역마다 번호(①②③…)를 달고 아래 두 표에서 같은 번호로 가리킨다. 승인·반려의 "누가"는 반드시 사람이다. 대표 예제는 자료 선택 → 출처 있는 초안 → AI 적대 검토 → 사람 검토·승인 → 배포 준비·실제 배포를 구분한다. 자료 없음·검토 지적·반려 시 흐름도 적는다. 모르는 동작은 [[확인 필요]]. 채운 예는 완성 예시 문서에 있다.</p>
