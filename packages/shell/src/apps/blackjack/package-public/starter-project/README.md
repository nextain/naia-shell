# 나이아 블랙잭 코딩 실습 (`naia-blackjack-studio`)

나이아 블랙잭 스튜디오에서 내보낸 로컬 실습 프로젝트입니다.

## 실습 방법

1. 터미널 또는 나이아 **프로젝트 앱(OpenCode / Claude Code / Codex)** 에서 이 폴더를 엽니다.
2. `blackjack-rules.js` 파일의 **Step 1 ~ Step 5** `TODO` 구간을 차례대로 구현합니다.
3. 나이아 블랙잭 스튜디오 가운데 상단의 **[로컬 파일 불러오기]** 단추를 누르면, 터미널에서 고친 `blackjack-rules.js` 코드가 스튜디오 편집기와 실전 카드 테이블·자동 채점기에 즉시 반영됩니다!
4. 브라우저에서 `index.html`을 직접 열어도 내 `blackjack-rules.js` 동작을 바로 시험해 볼 수 있습니다.
