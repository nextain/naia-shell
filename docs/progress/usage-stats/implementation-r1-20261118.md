# 사용 통계 구현 회차 1 — 웹GPU

요구서 범위: US-01~05, US-07, T-01, T-03, T-05, GAP-03.

기준선은 `feat/026-webgpu-r13-clean`이다. 저장소 `main`에는 웹GPU 웹판 UI가 없으며 이 기준선에는 웹 셸의 브라우저 WebGPU 모델 화면과 다운로드·답변 흐름이 있다. 따라서 이 가지에서 로컬 구현을 검토하고, PR도 이 기능 가지를 대상으로 분리한다.

## 이름표와 허용값

| 이름표 | 발생 시점 | 허용값 |
|---|---|---|
| `webgpu_model_download_start` | 모델 파일의 실제 네트워크 요청 시작(캐시 적중 제외) | 추가 속성 없음 |
| `webgpu_model_download_complete` | 모델 받기 완료 | 추가 속성 없음 |
| `webgpu_model_ready` | 모델 실행 준비 완료 | 추가 속성 없음 |
| `webgpu_model_download_fail` | 모델 받기 실패 | 추가 속성 없음 |
| `webgpu_unsupported` | 브라우저에서 WebGPU 기능 사용 불가 | 추가 속성 없음 |
| `webgpu_first_reply` | 첫 답변이 표시됨 | `elapsed_seconds`: 0 이상 유한한 초 숫자만 |
| `webgpu_reply_fail` | 첫 답변 표시 전 실패 | 추가 속성 없음 |

사용자 질문·답변, 모델/GPU 식별값, 파일 주소, 임의 오류 문자열, 계정·세션 값은 전송하지 않는다. 요청의 `page_location`은 고정된 `/webgpu` 주소이고 `page_referrer`는 빈 문자열이다. 실패 세부 분류와 경로는 이번 회차에서 보내지 않는다. 모델 기능과 답변은 분석 동의 여부와 무관하게 동작한다.

## 동의와 철회

웹 셸 진입에서 통계 선택을 제공하며, 웹 모드는 데스크톱 전용 경로 캐시를 읽지 않고 먼저 시작한다. `accepted`만 분석 수집을 허용하며 미선택·거절이면 태그, 식별자, 사건, 큐, 요청을 만들지 않는다. 허용한 뒤 설정/배너에서 철회하면 현재 탭과 다른 탭의 후속 요청·예약 전송을 즉시 중지하고 저장된 대기열을 지운다. 철회 후 새로고침과 로그인 왕복에서도 거절 상태를 유지한다. 동의 없이도 모델 준비와 채팅을 사용할 수 있다.

## 수신 대상 설정

웹GPU 개발판은 `VITE_WEBGPU_GA4_MEASUREMENT_ID` 환경 설정값만 사용한다. 이 값은 개발 전용 수신 ID 자리이며 현재 승인·확인된 측정 ID가 아니다. 값이 비거나 형식이 유효하지 않으면 태그를 넣거나 요청하지 않는다. 운영은 웹 `www.naia.land`와 별도의 GA4 속성을 쓰며 운영 속성 ID는 확인·승인 전까지 비워 둔다. 이 PR은 실제 GA4나 속성 설정을 바꾸지 않고 모든 브라우저 시험 요청을 모의 수신기로 가로챈다.

## 검증

T-01·T-03·T-05는 기존 시험 도구와 Playwright `page.on('request')`를 사용한다. `google-analytics.com` 및 `googletagmanager.com` 요청 수를 기록하며, 동의 전·거절·철회 후 0건이어야 한다. 금지 표식인 이메일, 질문 문장, 쿼리 및 인증값이 요청 본문·URL에 없어야 한다.

## 실행 결과

- 관련 Vitest 5개 파일/124개 테스트 통과. 새 `usage-analytics.test.ts`도 포함된다.
- Playwright T-01, T-03/T-05 2/2 통과. T-01 동의 전 0건·거절 후 0건. 철회 전 태그/수집 2/2건, 새 탭을 포함한 철회 후와 새로고침 뒤 추가 0건. 요청 본문에 개인정보 표식이 없음을 검사했다. 요청은 모의 수신기로만 가로챘다.
- `tsc -b --pretty false`, 새 분석 코드·컴포넌트·브라우저 시험에 대한 Biome 검사, `git diff --check` 통과.
- 전체 셸 Vitest는 322개 파일 중 317개 통과, 4개 실패, 1개 건너뜀(3,492 통과, 20 실패, 26 건너뜀). 실패는 전체 회귀 결과로 남겨 둔다.
- `build:web`는 타입 검사와 worker 검사 다음 단계에서 `jina/speech/atlas.bin`이 없어 중단됐다. `NAIA_WEB_NVA_ATLAS_SOURCE`에 줄 원본도 확인 못 함. 실기기 WebGPU 모델 다운로드 검증은 하지 않았다.
